# 📋 Attendance Tracker – Microsoft Excel

## 📌 Project Overview

A professional Excel-based Attendance Tracker designed to record, monitor, and analyze employee/student attendance efficiently. The tracker provides a structured way to maintain daily attendance records and quickly understand attendance performance through automated calculations and visual insights.

## 🎯 Objectives

- Maintain organized daily attendance records
- Calculate attendance percentages automatically
- Track Present, Absent, and Leave status
- Monitor individual attendance performance
- Reduce manual calculation errors
- Provide a simple and user-friendly tracking system

## 🛠️ Tools & Skills

- Microsoft Excel
- Excel Formulas
- Data Validation
- Conditional Formatting
- Data Organization
- Attendance Analysis
- Data Visualization

## 📊 Key Features

- Daily attendance recording
- Automated attendance calculations
- Present / Absent / Leave tracking
- Attendance percentage analysis
- Employee/Student-wise attendance summary
- Conditional formatting for quick identification
- Clean and easy-to-use Excel interface

## 💡 Benefits

The tracker makes attendance management faster and more organized. Automated calculations reduce manual work and help users quickly identify attendance patterns and individuals with low attendance percentages.
